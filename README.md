# 🍜 MenuBazar

### A Little Street. A Lot of Flavours.

MenuBazar is an immersive, interactive 3D restaurant discovery website where visitors can explore a miniature food street and discover restaurant menus.

Instead of browsing ordinary restaurant cards, visitors experience a miniature animated world where every restaurant has its own place.

## ✨ Features

- 🏙️ Interactive 3D miniature Indian food street.
- 🏪 Three featured restaurants:
  - Chhotu Dhaba
  - Hub 360
  - Dragon Delight
- 💡 Restaurant lights turn on when visitors select a building.
- 🎥 Smooth cinematic camera transitions.
- 📖 Displays original restaurant menu images.
- 🔍 Zoom functionality for reading menus.
- 📱 Responsive design for desktop and mobile.
- 🎨 Immersive visuals and animations.

## 🎯 Project Objective

To make discovering local restaurant menus more engaging through an interactive 3D experience.

**MenuBazar is a menu discovery platform, not a food ordering application.**

## 🚀 Getting Started

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate into the project:

```bash
cd MenuBazar
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 🗺️ User Journey

1. Open MenuBazar.
2. Enter the miniature food street.
3. Explore the three restaurant buildings.
4. Select a restaurant.
5. Watch its lights turn on.
6. View its original menu images.
7. Zoom in and explore the menu.
8. Return to the miniature street.

## 🌟 Vision

MenuBazar aims to transform ordinary digital menu browsing into a fun, visual and interactive discovery experience.
